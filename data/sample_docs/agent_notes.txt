Agent 应用开发课程笔记

Agent 不只是一次检索加一次生成。Agent 更强调状态管理和工具调度。一次用户请求进入系统后，Agent 可以先判断意图，再选择调用检索、导入、删除、统计或问答工具。

在一个课程资料 RAG Agent 中，RAG 是 Agent 的核心工具之一。RAG 工具负责从本地资料库中提供证据，Agent 负责决定什么时候调用它、如何处理低相关度结果、是否需要重试，以及最终如何组织回答。

CLI 和 FastAPI 的定位不同。CLI 适合开发阶段快速调试，比如测试文档导入、检索分数和拒答逻辑。FastAPI 适合演示工程交付能力，比如通过 Swagger 展示上传文档、批量导入、问答和统计接口。

Benchmark 的作用是让项目指标可复现。对于小规模课程资料，可以人工标注 10 到 20 个问题，并比较纯向量检索、纯 BM25 和混合检索在 Recall@K、Precision@K、拒答率和平均检索耗时上的差异。
